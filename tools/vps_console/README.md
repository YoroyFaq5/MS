# VPS console

Локальный инструмент для быстрых SSH-команд к продакшен-серверу — кнопки для
частых команд (статус сайта, деплой, логи, fail2ban) вместо ручной сборки
SSH-вызова каждый раз.

**Не часть сайта.** Отдельный процесс, не регистрируется в `app/__init__.py`,
не деплоится на прод. Держать root-доступ к VPS внутри публичного приложения
было бы опасно — любая уязвимость на сайте стала бы уязвимостью на сервере.

## Установка

```
pip install -r tools/vps_console/requirements.txt
cp tools/vps_console/.env.example tools/vps_console/.env
```

Заполните `tools/vps_console/.env` реальными `VPS_HOST`/`VPS_USER`/`VPS_PASS`.
Этот файл уже подпадает под общий `.gitignore` репозитория (шаблон `.env`
без указания пути matches на любой глубине) — в git не попадёт.

## Запуск

```
python tools/vps_console/server.py
```

Открыть http://127.0.0.1:5057 — сервер слушает **только localhost**,
наружу не открывать (ни `--host 0.0.0.0`, ни проброс порта).

## Что внутри

- Набор кнопок-пресетов на частые команды (см. `PRESETS` в `server.py`) —
  статус/рестарт сайта, деплой (`git pull` + рестарт), логи, `fail2ban`,
  место на диске, память, проверка сайта через `curl`.
- Поле для произвольной команды — для одноразовых Python-скриптов с боевыми
  кредами БД и т.п. (не хранится в пресетах намеренно — секреты вводятся
  вручную по месту, а не лежат готовой кнопкой в коде).
- Каждая команда выполняется отдельным SSH-подключением (как и раньше в
  разовых скриптах) — без постоянной сессии/tunneling.
